# MANAR — Design Notes

## Identity
- Logo: official SVG only, never modify
- Colors: #8B5CF6 / #A855F7 / #6B2F3A
- Base: near-black, layered surfaces
- Language: Arabic RTL first, English LTR second
- Dark mode is primary, light mode designed independently

## Five Layers
1. System Horizon
2. Navigation Spine
3. Command Core
4. Intelligence Rail
5. Command Dock
